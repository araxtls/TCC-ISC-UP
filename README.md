# TCC-ISC-UP
Analise de dados do TCC entitulado "Análise do Perfil Clínico, Microbiológico e do Consumo de Antimicrobianos em Infecções do Sítio Cirúrgico em um Hospital Universitário de Curitiba"

- Os dados foram coletados e organizados em planilhas eletrônicas, com posterior conferência de consistência e verificação de valores ausentes. As análises estatísticas foram realizadas no software R.
- Variáveis quantitativas foram descritas por meio de medidas de tendência central e dispersão, e variáveis categóricas foram apresentadas por meio de frequências absolutas e relativas.
- As distribuições de dados foram avaliadas por meio de inspeção gráfica e do teste de normalidade Shapiro - Wilk. Para associação entre variáveis quantitativas, foram utilizados coeficientes de correlação de Pearson ou Spearman. Para associação entre variáveis categóricas, foram utilizados os testes Qui-Quadrado ou teste exato de Fisher. Para associação não paramétrica entre grupos, foram utilizados os testes de Wilcoxon e Kruskal-Wallis.
- Visando compreender a relação entre as múltiplas variáveis associadas e potencialmente explicativas do desfecho óbito, optou-se também pela criação de modelos de regressão logística binária multivariada. Por fim, foi adotado nível de significância de 5% (p < 0,05) para todas as análises.
